# lnreader-libs.js

Generated bundle of the JS libraries LNReader plugins `require()`. Checked in on purpose:
it is regenerated by hand, not by the Gradle build.

To regenerate:

```bash
npm install cheerio@1.0.0-rc.12 htmlparser2 dayjs @noble/ciphers esbuild
npx esbuild entry.mjs --bundle --outfile=../src/main/assets/lnreader-libs.js \
  --format=iife --platform=browser --target=es2020 --minify --define:global=globalThis
```

Notes:
- The npm `urlencode` package is deliberately NOT used: it pulls iconv-lite, which needs node's
  `buffer`/`string_decoder`. `entry.mjs` implements encode/decode against TextEncoder/TextDecoder
  instead, which covers legacy-charset decode (gbk, big5, shift_jis, euc-kr) natively in a WebView.
- `protobufjs` is omitted, so `@libs/fetch`'s `fetchProto` is unavailable. Only a handful of
  plugins use it; add protobufjs here if one is needed.
